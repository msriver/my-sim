# SIM — Simple Issue Management

사내 정책상 GitHub나 Jira를 사용할 수 없는 환경에서 만들게 된, 완전 로컬 기반 이슈 트래커입니다. Claude Code와 함께 사용하는 것을 전제로 만들어졌습니다.

이슈를 만들어두고, 그 이슈를 선택해서 다른 폴더의 프로젝트(기본값 `../target-project`)에서
Claude Code(`claude` CLI)를 앱에 내장된 터미널에서 바로 띄우는 게 핵심 동작입니다. 이슈의
제목과 내용이 그대로 Claude Code의 초기 프롬프트로 들어갑니다.

## 시작하기

`claude` CLI가 PATH에 설정되어 있어야 합니다 (Claude Code 실행 버튼을 눌렀을 때 이 CLI를
그대로 스폰합니다).

```bash
npm install
npm run dev
```

`npm run dev`를 실행하면 앱 창이 뜹니다. 
`npm run build`를 실행하면 타입 체크를 수행한 뒤 프로덕션 번들을 out/에 생성합니다. 
`npm run start`로 그 번들을 미리 볼 수 있습니다. 아직 설치파일(.exe 등)
패키징은 붙어있지 않습니다.

## 사용법

- 사이드바 상단의 `+ 새 이슈`로 제목/내용/우선순위를 입력해 이슈를 만듭니다.
- 검색창과 상태 필터로 사이드바 목록을 좁힐 수 있습니다.
- 이슈를 클릭하면 상세 화면이 뜹니다. 상태는 드롭다운으로 TODO / IN PROGRESS / DONE 중 원하는 상태를
  바로 선택할 수 있고, `수정` / `삭제` 버튼도 상단에 있습니다. 실행 중인 세션이 있는 이슈는 삭제할 수 없습니다. — 먼저 세션을 종료해야 합니다.
- `▶ Claude Code 실행`을 누르면 앱 내장 터미널(xterm.js + node-pty)이 뜨고, 이슈 제목과 내용을 초기 프롬프트로 사용하여 
  `claude` CLI가 대화형으로 실행됩니다. 이슈별로 여러 세션을 독립적으로 실행할 수 있지만, **같은 대상 프로젝트를 쓰는 세션은 동시에 하나만** 허용됩니다
  (이미 실행 중이면 어느 이슈가 쓰고 있는지 토스트로 알려줍니다).
- `← 목록으로`로 나가도 세션은 백그라운드에서 계속 살아있고, 다시 그 이슈를 선택하면 하던 그대로 돌아와 있습니다. 완전히 끝내려면 터미널 화면의 `세션종료` 버튼을 눌러야 합니다.
- 삭제한 이슈는 헤더의 `🗑 휴지통`에서 복구할 수 있습니다 (실제 파일은 삭제되지 않으며, 소프트 삭제 방식으로 동작합니다.).

## 데이터

이슈는 `issues/` 폴더에 마크다운 + frontmatter 파일(`<id>-<slug>.md`)로 저장됩니다. 파일을
직접 열어서 편집해도 무방합니다 — 특히 긴 설명을 쓸 때는 이 편이 더 편할 수 있습니다.

현재는 단순한 파일 기반 저장 방식을 사용합니다. 필요해지면 SQLite 등 다른 저장소로 변경할 예정입니다.

## 설정

`.my-sim/config.json`에 기본 대상 프로젝트 경로(`defaultTargetProject`)가 저장됩니다.

- **최초 실행 시** 대상 프로젝트 경로가 존재하지 않으면(예: 처음 설치했거나 폴더가 삭제된 경우) 앱 창이
  뜨기 전에 폴더 선택 팝업이 먼저 뜹니다. 여기서 대상 프로젝트 폴더를 지정하면 그대로 저장됩니다.
  팝업을 취소해도 앱은 실행되고, 나중에 아래 방법으로 다시 지정할 수 있습니다.
- **언제든 변경**하려면 헤더의 `⚙ 환경설정`에서 경로를 직접 입력하거나 `폴더 선택` 버튼으로
  다시 지정한 뒤 저장하면 됩니다.
- 특정 이슈만 다른 프로젝트에서 작업하고 싶다면, 이슈 수정 화면에서 대상 프로젝트 경로를 별도로 지정하면 됩니다.(`.md` 파일 frontmatter의 `targetProject` 필드로 저장됩니다).

## 기술 스택

- **Electron** + **electron-vite** — 메인/프리로드/렌더러 3-프로세스 구조
- **React** + **TypeScript** — 렌더러 UI
- **node-pty** + **xterm.js**(`@xterm/xterm`, `@xterm/addon-fit`) — 앱 내장 터미널, Claude Code를
  실제 pty로 대화형 실행
- **gray-matter** — 이슈 마크다운 파일의 frontmatter 파싱/직렬화
- **marked** — 이슈 본문 마크다운 렌더링
