# SIM — Simple Issue Management

사내 정책상 GitHub/Jira를 쓸 수 없는 환경을 위한, 완전 로컬 동작 이슈 트래커(데스크톱 앱)입니다.
이슈를 관리하고, 선택한 이슈로 다른 폴더의 프로젝트(기본값: `../target-project`)에서
Claude Code(`claude` CLI)를 앱 내장 터미널로 바로 실행할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

Electron 창이 뜹니다. `npm run build`로 배포용 번들을 만들 수 있습니다 (패키징/설치파일 생성은 아직 없음).

## 사용법

- 좌측 사이드바에서 이슈 목록을 보고 클릭해서 선택합니다.
- `+ 새 이슈`로 제목/내용/우선순위를 입력해 새 이슈를 만듭니다.
- 이슈 상세 화면에서 `상태변경` 버튼으로 상태(todo → in-progress → done)를 바꿉니다.
- `▶ Claude Code 실행`을 누르면 앱 안에 내장된 터미널(xterm.js + node-pty)이 뜨고,
  대상 프로젝트 폴더에서 이슈 제목+내용을 프롬프트로 `claude` CLI가 대화형으로 실행됩니다.
- Claude Code 세션을 정상 종료하면(`exit` 등) 자동으로 이슈 화면으로 돌아갑니다.
  `← 목록으로` 버튼으로 직접 나가면 그 세션은 종료됩니다.

## 데이터

이슈는 `issues/` 폴더에 마크다운+frontmatter 파일(`<id>-<slug>.md`)로 저장됩니다.
파일을 직접 열어서 편집해도 됩니다 (특히 긴 설명을 작성할 때 유용합니다).

## 설정

`.my-sim/config.json`에 기본 대상 프로젝트 경로(`defaultTargetProject`)가 저장됩니다.

- **최초 실행 시**, 이 경로가 실제로 존재하지 않으면(처음 설치했거나 폴더가 없어졌거나) 앱이 뜨기
  전에 폴더 선택 팝업이 나타납니다. 여기서 대상 프로젝트 폴더를 지정하면 그대로 저장됩니다. 팝업을
  취소해도 앱은 실행되며, 나중에 아래 방법으로 다시 지정할 수 있습니다.
- **언제든 변경**하려면 사이드바의 `⚙ 환경설정`을 눌러 경로를 직접 입력하거나 `폴더 선택` 버튼으로
  다시 지정한 뒤 저장하면 됩니다.
- 이슈별로 다른 프로젝트를 대상으로 하고 싶다면 해당 이슈 `.md` 파일의 frontmatter에
  `targetProject: <경로 또는 폴더명>`을 추가하세요.
